# 🧮 BMI Calculator

A Python-based BMI Calculator with a graphical user interface using Tkinter.

The application allows users to enter their weight and height, calculate their BMI, view their BMI category, maintain BMI history, and view their BMI trend.

## ✨ Features

- 🖥️ Graphical User Interface using Tkinter
- ⚖️ Weight input in kilograms
- 📏 Height input in centimeters
- 🧮 Automatic BMI calculation
- 📊 BMI category classification
- 📜 BMI history
- 📈 BMI trend
- 🧹 Clear input fields
- ❌ Input validation and error handling

## 📊 BMI Categories

| BMI Range | Category |
|-----------|----------|
| Below 18.5 | Underweight |
| 18.5 – 24.9 | Normal Weight |
| 25 – 29.9 | Overweight |
| 30 and above | Obese |

## 🛠️ Technologies Used

- Python
- Tkinter
- Datetime
