# 🎙️ Voice Assistant

A Python-based voice assistant that listens to spoken commands, processes them, and responds using speech.

## 📌 Features

- 🎤 Voice input using microphone
- 🔊 Text-to-speech responses
- 👋 Greeting commands
- 🕐 Current time
- 📅 Current date
- 🌐 Web search using Google
- ❌ Speech recognition error handling
- 🛑 Voice-controlled exit command

## 🛠️ Technologies Used

- Python
- SpeechRecognition
- PyAudio
- pyttsx3
- datetime
- webbrowser
